# GregLineMakerResources

Generated data/asset payload for [GregLineMaker](https://github.com/owlyfans/GregLineMaker),
published here (via GitHub Pages) instead of living inside the main app repo, since it's large
(~110MB) and fully regenerable from a TerraFirmaGreg-Modern instance via that repo's `mod/` +
`pipeline/`.

## Contents

- **`recipes.json`** - the normalized recipe database (`pipeline/build.mjs`'s output, copied
  verbatim from the main repo's `data/recipes.json`).
- **`icons.json`** - id → icon URL manifest. Unlike the main repo's own copy of this file (which
  `pipeline/extract_icons.mjs` writes with root-relative paths, e.g. `/icons/items/gtceu/...`), the
  values here are rewritten to full `https://owlyfans.github.io/GregLineMakerResources/...` URLs so
  the app can use them directly as `<img src>` with no base-URL logic of its own.
- **`icons/`** - the actual icon PNGs the manifest points at (`icons/items/<namespace>/<path>.png`).

## Publishing

GitHub Pages is set to serve this repo's root directly (Settings → Pages → Source: Deploy from a
branch → `main` / `/`). No build step - these are static files, served as-is.

## Updating

This repo's content is regenerated by the main repo's pipeline, not edited by hand:

1. In the main repo, run the pipeline (`mod/`'s in-game dump commands, then
   `pipeline/npm run build` and `pipeline/node extract_icons.mjs`) to refresh
   `data/recipes.json` / `app/public/icons/` / `app/public/data/icons.json`.
2. Copy `data/recipes.json` here as `recipes.json`.
3. Copy `app/public/icons/` here as `icons/`.
4. Regenerate `icons.json` here from the main repo's `app/public/data/icons.json`, rewriting each
   value from a root-relative path to `https://owlyfans.github.io/GregLineMakerResources<path>`.
5. Commit and push - Pages picks up the update automatically.

# GregLineMakerResources

Generated data/asset payload for [GregLineMaker](https://github.com/owlyfans/GregLineMaker),
published here (via GitHub Pages) instead of living inside the main app repo, since it's large
(~110MB) and fully regenerable from a TerraFirmaGreg-Modern instance via that repo's `mod/` +
`pipeline/`.

## Contents

- **`<version>/recipes.json`** (e.g. `0.13.4/recipes.json`, `0.13.5/recipes.json`) - the normalized
  recipe database for that modpack revision (`pipeline/build.mjs`'s output, copied verbatim from
  the main repo's `data/<version>/recipes.json`). Versioned because recipes shift across pack
  updates (mods added/removed/bumped) - see the main repo's `app/src/config.ts` for the version
  list the app's settings dropdown offers, and keep both in sync when a new pack version ships.
- **`icons.json`** - id → icon URL manifest, shared across all versions (item ids - and therefore
  icon URLs - don't change underneath an existing id when the pack updates, they only ever gain new
  ones). Unlike the main repo's own copy of this file (which `pipeline/extract_icons.mjs` writes
  with root-relative paths, e.g. `/icons/items/gtceu/...`), the values here are rewritten to full
  `https://owlyfans.github.io/GregLineMakerResources/...` URLs so the app can use them directly as
  `<img src>` with no base-URL logic of its own.
- **`icons/`** - the actual icon PNGs the manifest points at (`icons/items/<namespace>/<path>.png`),
  also shared across versions.

## Publishing

GitHub Pages is set to serve this repo's root directly (Settings → Pages → Source: Deploy from a
branch → `main` / `/`). No build step - these are static files, served as-is.

## Updating

This repo's content is regenerated by the main repo's pipeline, not edited by hand:

1. In the main repo, run the pipeline (`mod/`'s in-game dump commands, then
   `pipeline/npm run build` - pass the modpack version as a second arg or via
   `GREGLINE_MODPACK_VERSION`, e.g. `node build.mjs "" 0.13.5` - and
   `pipeline/node extract_icons.mjs`) to refresh `data/<version>/recipes.json` /
   `app/public/icons/` / `app/public/data/icons.json`.
2. Copy `data/<version>/recipes.json` here as `<version>/recipes.json` (create the folder for a new
   version the first time).
3. Copy `app/public/icons/` here as `icons/` (merge in, don't wipe other versions' icons - it's a
   shared folder).
4. Regenerate `icons.json` here from the main repo's `app/public/data/icons.json`, rewriting each
   value from a root-relative path to `https://owlyfans.github.io/GregLineMakerResources<path>`.
5. Commit and push - Pages picks up the update automatically.
